# EquiEdu v3 — principais mudanças

## Diagnóstico

- removido o teste fixo sobre oportunidades e robótica;
- recorte corrigido para 5º ano (fim dos EFAI) e 9º ano (fim dos EFAF);
- banco de questões começa vazio;
- somente questões validadas e ativas aparecem;
- cadastro de matéria, habilidade, idioma, fonte, alternativas e gabarito;
- códigos de escola e turma no lugar de nomes;
- resultados gerais e por matéria.

## Dados e transparência

- removidos integrantes, missões, pontuações, oportunidades e indicadores fictícios;
- resultados aparecem somente após aplicações salvas no navegador;
- médias de grupos com menos de cinco aplicações ficam ocultas;
- painel deixa claro que não há dados de exemplo;
- oportunidades começam vazias e exigem verificação.

## Gestão

- banco de questões colocado como primeira área;
- modelo JSON para receber questões;
- importação por arquivo ou texto;
- função para mesclar arquivos de vários professores;
- backup completo do projeto;
- documentação para editar tudo depois.

## Interface

- página inicial redesenhada;
- navegação focada no objetivo do EquiEdu;
- modo claro e escuro no cabeçalho;
- painel de acessibilidade preservado e melhorado;
- layout responsivo;
- fluxo principal em português, Guarani (Avañe'ẽ), inglês, espanhol, alemão e francês;
- aviso responsável para validar a tradução Guarani com falantes e educadores.

## Projeto

- metodologia reescrita para a reunião com os professores;
- pedido aos docentes detalhado;
- proteção de dados e limites do piloto registrados;
- guia curto de reunião incluído no ZIP.
